VIETEXPLORE TRAVEL - WEBSITE DEMO

Cách chạy:
1. Giải nén file ZIP.
2. Mở file index.html bằng Chrome/Edge.
3. Website chạy trực tiếp, không cần cài server.

Các chức năng:
- Trang chủ
- Danh sách 6 tour mẫu
- Xem chi tiết tour bằng popup
- Sản phẩm du lịch
- Form đặt tour giả lập
- Tạo mã đặt tour demo
- Responsive cho điện thoại
- Không thanh toán thật
- Không lưu dữ liệu

Lưu ý:
- Hình ảnh hiện dùng ảnh từ Unsplash qua Internet. Nếu trình diễn không có mạng, nên tải ảnh về và thay URL trong script.js/style.css.
- Toàn bộ giá, tour, hotline và địa chỉ đều là dữ liệu minh họa.
